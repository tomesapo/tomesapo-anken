1. はじめに

このシステムでできること

本システムは、駐車場仲介業務を一元的に管理するために設計された Web ベースの業務システムです。主な機能は以下のとおりです。

  • 案件管理: 依頼受付から契約・請求・入金までの案件ライフサイクルを管理
  • マスタ管理: 顧客・拠点・担当者・自社支店・仕入先の情報を一元化
  • 駐車場DB: 過去に取り扱った駐車場をデータベース化し、再利用可能に
  • 帳票出力: 提案資料・確定資料・請求書・申込書・契約書を自動生成
  • メール下書き: 案件状況に応じた定型メールを Outlook で自動作成
  • 分析・レポート: カレンダー・取引分析・売上集計・月次レポート・保証金管理

動作環境

  • PC: Windows / Mac の最新版 Chrome、Edge、Safari、Firefox
  • スマートフォン・タブレット: Safari (iOS)、Chrome (Android) ※モバイル最適化済み
  • インターネット接続: 必須（Firebase でリアルタイム同期）
  • メーラー連携: Outlook（クラシック）を既定メールクライアントに設定推奨
💡 ホーム画面に追加すると便利 本システムは PWA（プログレッシブ Web アプリ）対応です。スマホ・PC のブラウザから「ホーム画面に追加」「アプリとしてインストール」を行うと、ネイティブアプリのようにアイコンから起動できます。

本マニュアルの読み方

業務の流れに沿って章を構成しています。初めて使う方は 3. 業務フロー全体像 から読むと、システムの全体像が掴みやすいです。特定の機能を調べたいときは左サイドバーから該当章にジャンプしてください。

3. 業務フロー全体像

標準的な案件は以下の流れで進みます。各ステップで該当するステータスに更新していくことで、案件の現在地が一目でわかります。

未調査→ 調査中→ 提案済→ 未申込→ 契約中→ 未請求→ 請求済→ 入金済
ステップ主な操作システム上の作業
1. 依頼受付顧客から依頼を受ける新規案件登録（ステータス：未調査）
2. 調査開始近隣駐車場を調査ステータスを調査中に更新。駐車場DBから候補を追加
3. 提案提案資料を作成・送付「📥 提案資料」ボタンで Excel 出力 → 提案メール送付
4. 申込顧客が申込を決定確定金額を入力し、確定資料を出力。申込書（Excel）を仕入先へ送付
5. 契約契約書締結契約書（Word）を出力。ステータスを契約中に
6. 請求請求書発行「📥 請求書出力」ボタンで Excel 出力 → 請求メール送付
7. 入金確認入金確認入金日と入金額を入力。ステータスは入金済に
📌 ポイント ステータスを保存した瞬間に、対応するメール下書き作成バナーが画面下部に表示されます（提案済・未請求・請求済時）。バナーから「📧 メーラーで開く」を押すと、Outlook で定型メールが立ち上がります。

5. 案件の新規登録

登録手順

  1. ヘッダー右上の ➕ 新規案件 ボタンをクリック（モバイルは画面右下の ＋ FAB ボタン）
  2. 案件登録モーダルが開いたら、上から順に入力
  3. 必要項目を入力後、最下部の 💾 保存 をクリック

入力項目（主要なもの）

項目必須備考
案件種別○通常 / 追加 / 延長
案件番号自動顧客を選ぶと自動採番。手動編集も可能
ステータス○初期値は未調査
依頼受付日○新規案件は今日が自動でセットされます
顧客名 / 拠点 / 担当者○マスタから選択。未登録の場合は先にマスタ登録を
現場名 / 現場住所○顧客に提示する物件情報
依頼開始日・終了日・台数推奨カレンダー機能で利用
提案日 / 見積売上・仕入提案時提案メール作成バナー表示の条件
確定売上・仕入確定時確定メール作成バナー表示の条件
請求日 / 入金日・入金額請求時請求書出力・売上集計に反映
駐車場（複数登録可）○「＋ 駐車場を追加」 または 「🅿 駐車場DBから追加」

業者費用の表示モード（3モード選択）

案件編集画面の「業者費用 別建て表示」セクションで、帳票（提案資料・確定資料・請求書）における業者費用の表示方法を3つから選べます。

モード賃料欄の表示業者費用行用途
なし
（デフォルト）		見積額表示しない通常の取引。シンプルに金額を提示
自動計算仕入額
（税抜換算）		見積－仕入
の差額を自動表示		顧客に「実費＋手配料」の内訳を見せたい場合（仕入をそのまま開示）
任意金額見積額
（上乗せ込み）		業者費用単価×台数
を別行表示		賃料に上乗せして利益を取りつつ、業者費用も別途いただく標準的なパターン

「任意金額」モードの例

前提: 仕入8,000円/月、見積10,000円/月（上乗せ2,000円）、業者費用単価5,000円/台、駐車場A: 3台×3ヶ月

項目単価数量金額
賃料（3ヶ月分）¥10,0003台×3ヶ月¥90,000
業者費用¥5,0003台¥15,000
小計（税抜）¥105,000

名目（行ラベル）の選択

業者費用行の名目は「業者費用」「手配料」「外注費」から選択できます（3モード共通）。顧客や業界の慣習に合わせて使い分けてください。

「任意金額」モードの仕様詳細

  • 業者費用単価は案件全体に1つ: 案件画面で1回入力すれば、すべての駐車場に同じ単価が適用されます
  • 期間中1回の一時金: 月数では掛け算しません（礼金と同じ扱い）
  • 駐車場ごとに台数分の業者費用: 駐車場A(3台)=15,000円、駐車場B(2台)=10,000円、合計25,000円
  • 業者費用単価が0または未入力なら業者費用行は出ない
📌 「自動計算」モードの注意 「自動計算」モードでは仕入額がそのまま顧客に見えてしまいます（業者費用＝粗利が明確に開示される）。粗利を隠したい場合は「なし」または「任意金額」モードを選んでください。
⚠ マイナス警告 「自動計算」モードで仕入＞見積の逆ザヤ状態だと、保存時にトースト警告「⚠ 〇〇：業者費用がマイナスです」が表示されます。設定ミスや赤字案件の検知に活用してください。

6. 案件の編集・状態更新

編集方法

案件一覧で対象案件の行をクリックすると詳細パネルが開きます。右上の ✏ 編集 をクリックすると、新規登録と同じフォームで編集できます。

一覧画面の各行末尾にある 編集 ボタンからも直接編集可能です。

状態更新のタイミングとバナー

保存時、以下の条件を満たすと自動でメール下書き作成のバナーが画面下部に表示されます。

状況表示条件バナー内容
提案完了提案済 + 見積売上・仕入 + 提案日 が入力済📧 提案メール作成バナー
確定金額入力未請求 + 確定売上・仕入 が入力済📧 確定メール作成バナー
請求書発行請求済 + 請求日 が入力済📧 請求メール作成バナー
📌 ステータス変更の入力チェック ステータスごとに必須項目が定義されており、不足している場合は警告が表示されます（例：請求済にしようとしたが請求日が未入力など）。警告を確認のうえ進めてください。

7. 案件詳細と帳票出力

詳細パネルの構成

一覧で案件をクリックすると、詳細パネルが右からスライドインします。以下のセクションで構成されています。

  • 確定情報: 確定売上・仕入・粗利
  • 請求・入金情報: 請求日・入金日・入金額
  • 駐車場情報: 紐づく駐車場と「📥 提案資料」「📋 確定資料」ボタン
  • メール下書き履歴: 過去に作成したメールを再オープン可能

詳細パネル下部のアクションボタン

ボタン機能

PC版の一覧表では、各列ヘッダーをクリックすると昇順／降順で並び替えできます。もう一度クリックで逆順に切り替わります。

9. 削除と復元（ゴミ箱）

削除

案件・顧客・駐車場・拠点は削除しても完全には消えず、ゴミ箱に移動します（論理削除）。

  • 案件: 詳細パネルの 🗑 削除 ボタン、または一覧の行末ボタン
  • 顧客・拠点・仕入先: マスタ管理画面の各削除ボタン
  • 駐車場: 駐車場DB画面の削除ボタン

復元・完全削除

ヘッダー ⚙ データ ▾ → 🗑 ゴミ箱 から、削除済みアイテムを管理できます。

  • 上部タブで「案件」「顧客」「駐車場」「拠点」を切り替え
  • 各行の ♻ 復元 ボタンで元の状態に戻す
  • 各行の 🗑 完全削除 ボタンで Firestore からも完全削除（取り消し不可）
⚠ 完全削除は取り消せません 完全削除を実行すると、データは復旧できなくなります。確認のうえ慎重に操作してください。通常は復元できる「論理削除」のままで運用することを推奨します。

10. 顧客マスタの管理

ヘッダー ⚙ データ ▾ → 🏢 マスタ管理 から、上部タブで「顧客」を選択します。

階層構造

顧客情報は3階層で管理されます。

  • 顧客（会社）─ 顧客コード（自動採番）、社名
  • 　└ 拠点（本社・支店）─ 名称、電話、郵便番号、住所、支払サイト、請求書送付方法
  • 　　　└ 担当者（スタッフ）─ 氏名、携帯、メール

新規追加・編集

  1. 顧客追加: ＋ 顧客を追加 ボタンから
  2. 拠点追加: 顧客カード内の ＋拠点追加 ボタンから
  3. 担当者追加: 拠点内の ＋追加 ボタンから
  4. 編集: 各入力欄を直接編集（保存ボタンで反映）

請求書送付方法

拠点ごとに「郵送 / メール / FAX / 手渡し / 電子請求」から選択。請求業務時の判断材料になります。

11. 自社支店の管理

マスタ管理画面の 「自社拠点」 タブで管理します。請求書・提案資料・確定資料に記載される自社情報です。

登録項目

  • 支店名・郵便番号・住所・電話・FAX・メール
  • スタッフリスト（氏名・携帯）
  • 角印（社印）画像 ─ 請求書に押印
  • 銀行印画像 ─ 必要時に使用
  • 振込先情報 ─ 銀行名・支店名・口座種別・口座番号・口座名義（請求書に記載）
  • インボイス登録番号
  • 既定支店フラグ ─ 新規案件で初期選択される支店
💡 印鑑画像の準備 印鑑画像は背景が透過された PNG を推奨します。請求書出力時に「角印あり / 角印なし」を選択できるので、状況に応じて使い分けできます。

12. 仕入先（地主・管理会社）の管理

マスタ管理画面の 「仕入先」 タブで管理します。駐車場の地主・管理会社を登録しておくと、案件登録時に呼び出せます。

登録項目

  • 区分: 地主 または 管理会社
  • 仕入先名・電話・FAX・メール
  • 課税事業者フラグ（チェックを入れると消費税対象として扱う）
  • インボイス登録番号（適格請求書発行事業者番号）
  • メモ欄
📌 課税フラグの重要性 地主は通常「免税事業者（非課税）」、管理会社は通常「課税事業者」です。フラグを正しく設定しておくと、見積・確定の自動計算で消費税が正確に処理されます。

13. メール雛形の管理

マスタ管理画面の 「メール雛形」 タブで、4種類のメール雛形を編集できます。

種別用途主要な変数
提案メール提案資料の送付{customerName}, {siteName}, {staffName} 等
確定メール契約確定の連絡同上 + 確定金額
請求メール請求書の送付同上 + 請求金額・期日
申込書FAXメール申込書を仕入先へFAX依頼仕入先情報・駐車場情報

使用可能な変数

雛形内で {変数名} と書くと、案件データに置き換えられます。代表的な変数:

  • {customerName} 顧客名 / {staffName} 担当者名 / {baseName} 拠点名
  • {siteName} 現場名 / {caseNo} 案件番号
  • {branchName} 自社支店名 / {ourStaffName} 自社担当者名 / {ourStaffMobile} 自社担当者携帯
  • {branchEmail} 自社メール

操作ボタン

  • 🔄 デフォルトに戻す: 現在表示中のタブだけを初期雛形に戻す
  • 🔁 全タブ一括リセット: 4種類すべてを初期雛形に戻す（要注意）
  • 👁 プレビュー: 変数を仮データで埋めた結果を確認
  • 💾 保存: 変更を保存

14. 駐車場データベース

ヘッダー ⚙ データ ▾ → 🅿 駐車場DB から開きます。過去に取り扱った駐車場をデータベース化し、新規案件で再利用できます。

表示モード

モード用途
📋 一覧テーブル形式で駐車場を一覧表示。検索・編集・削除が可能
🗺 マップ地図上にピンで駐車場を表示。半径検索が可能

地図機能

  • 住所を登録すると、自動的に緯度経度を取得して地図上にピン表示
  • 「案件を表示」ボタンで、現在進行中の案件現場を地図上に重ね表示
  • 検索ボックスで駐車場名・住所による絞り込み

案件への取り込み

案件編集画面で 🅿 駐車場DBから追加 ボタンを押すと、DB から駐車場を選んで案件に紐づけられます。同じ駐車場を複数の案件で再利用できるため、入力の手間を大幅に削減できます。

案件→DBへの登録

案件内の駐車場カードにある 📤 DB登録/更新 ボタンで、案件側で編集した駐車場情報を DB に反映できます。

20. メール下書きの作成

メーラー連携の仕組み

本システムは mailto: リンク経由で OS の既定メールクライアントを起動します。Outlook（クラシック版）を既定メーラーに設定しておくと、宛先・件名・本文がすべて反映された状態で新規メール作成画面が立ち上がります。

バナーからの作成

案件保存時、条件を満たすと画面下部に 「📧 ◯◯メールを作成しますか？」 バナーが表示されます。

  1. メールを作成 ボタンをクリック
  2. Outlook の新規メール画面が開く（宛先・件名・本文入力済）
  3. 必要に応じて内容を修正し、Excel ファイル（提案資料・請求書など）を添付
  4. 送信

過去メールの再オープン

案件詳細パネルの「📬 メール下書き履歴」セクションから、過去に作成したメールを 📧 メーラーで開く ボタンで再表示できます。送信済みのものには ✓ 送信済みマークを付けて管理できます。

⚠ Outlook 新版では本文が切れる場合があります Outlook（新版）は mailto: 経由の長文・改行に弱いため、Outlook（クラシック）を既定メーラーに設定してください。Windows の「設定 → アプリ → 既定のアプリ」から MAILTO ハンドラを Outlook（クラシック）に変更します。

24. よくあるトラブルと対処法

Q. メーラーで「有効なメールアドレスを入力してください」と出る

メールアドレスに 全角の「＠」 が混入している可能性が高いです。マスタの担当者メール欄を確認し、半角「@」に修正してください。

Q. メール下書きバナーが出ない

バナー表示には必須項目が揃っている必要があります。

  • 提案メール: ステータス提案済 + 提案日 + 見積売上・仕入
  • 確定メール: ステータス未請求 + 確定売上・仕入
  • 請求メール: ステータス請求済 + 請求日

条件を満たして保存し直すと表示されます。

Q. 請求書出力ボタンが表示されない

請求書出力ボタンはステータスが 未請求・請求済・入金済の時のみ表示されます。ステータスを更新してください。

Q. Excel ファイルが上書き保存できない（権限エラー）

同じファイルを Excel で開いている可能性があります。Excel を閉じてから再度出力してください。

Q. 地図にピンが表示されない

住所から緯度経度を取得できなかった可能性があります。駐車場DBで該当駐車場の住所を確認し、町名・番地まで正確に入力してください。

Q. データが反映されない・古いデータが表示される

ブラウザのキャッシュが原因の場合があります。以下を試してください。

  1. Ctrl + F5 でハードリロード（Mac は Cmd + Shift + R）
  2. それでもダメな場合は、ブラウザの設定からキャッシュを削除

Q. ログアウトしてしまった

ヘッダー右上の「ログイン」から再度ログインしてください。データは Firebase に保存されているため失われません。

Q. 間違って削除してしまった

ヘッダー ⚙ データ ▾ → 🗑 ゴミ箱 から復元可能です。完全削除していない限り元に戻せます。
